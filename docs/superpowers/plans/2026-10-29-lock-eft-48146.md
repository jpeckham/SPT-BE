# EFT 48146 baseline lock-in plan

Goal: preserve the current installation and source state for EFT 1.2.5.0.48146 before any newer-version work.

1. Capture all repository commits, branches, dirty patches/untracked files, and worktree paths locally. Tags identify workspace states, not proof that every checkout produced installed binaries.
2. Inventory the installation, hash executables/DLLs and metadata, and back up mutable configuration/profile data. Confirm no process uses the installation.
3. Rename only C:\sptarkov\SPTarkov 5.0.0-local to C:\sptarkov\SPTarkov 5.0.0-BE-1.2.5.0.48146. Update launcher GamePath and shortcuts that actually point to the old path.
4. Create spt-5.0-eft-1.2.5.0.48146 branches in the five mod forks. Update tracked build defaults and current instructions; retain the old remote branches. Commit and tag the baseline in these forks, pushing only to James's remotes.
5. Verify hashes after the move, launcher path, and builds using the new defaults. Document known unresolved Freecam and FPS issues; this baseline is not a claim of complete validation. Preserve historical README commands with a relocation notice.

No new EFT installation/update, upstream publication, remote branch deletion, or game launch is part of this task.
